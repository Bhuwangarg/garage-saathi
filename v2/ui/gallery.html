What this does not measure

Painting and compositing (the clock stops after layout), scrolling smoothness, the real Hindi font, the real data and the code that reads it, hover, other programs running, and any width other than this window's. The rows are stand-ins with the same parts as the real ones, built by the real drawing, figure and row styles. A reading from here is the cost of drawing a list on this computer and nothing wider.
