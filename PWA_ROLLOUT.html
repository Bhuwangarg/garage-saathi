Moving staff phones to the web app

Garage Saathi · decided 9 September 2026

Why we are doing this

The installed Android/iPhone app carries its own frozen copy of the code. It never fetches anything from the server, so no update can reach it — however many times we fix something.

On 9 September the copy inside it was dated 2 August. Five weeks old. It had no crew bank, no Crew Manager login, and none of the sync repairs. A phone running it could not show a person added that week, and — because the old code reported an expired session as “Offline” — it had quietly stopped receiving anything at all while still looking like it worked.

The web app has no such gap. It checks for new code every time it opens online, so a fix reaches every phone on its own.

What each person does, once

Open Chrome on Android, or Safari on iPhone — on an iPhone it must be Safari, Chrome cannot do this — and go to:

https://garage-saathi-sync.vercel.app
  1. Android: ⋮ menu → Install app (or Add to Home screen).
  2. iPhone: Share button → Add to Home Screen.
  3. Open it from the new icon, and log in once while the internet is on, so the phone gets a session and pulls the staff list.

क्रोम में (आईफ़ोन पर सफ़ारी में) यह पता खोलिए, मेन्यू से होम स्क्रीन पर जोड़ें दबाइए, फिर नए आइकन से ऐप खोलकर एक बार इंटरनेट चालू रखते हुए लॉगिन कीजिए। पुराना ऐप फ़ोन से हटा दीजिए।

Then delete the old app

This is the step that matters

Uninstall Garage Saathi (com.mahalaxmi.garagesaathi) from every phone.

Both icons look the same. A phone left on the old one keeps showing five-week-old data and gets no warning — its code is frozen, and the only message the server can make it display is a PIN lockout. There is no way to tell it to update. Removing it is the only reliable fix.

Checking a phone is on the new one

Open Me → Sync.

  • If there is a ⤓ Re-download everything button, the phone is running current code. That button only exists in the new version, so seeing it is proof.
  • If it is missing, they are still on the old app — check which icon they opened.
While you are on that screen

Status now tells the truth. “Signed out — log in again to sync” means exactly that; it used to be hidden behind the word “Offline”, which is how a phone could stop receiving records for days without anybody noticing.

Do not sideload the old app again

mobile/ stays in the repo as a working native project, but it is not maintained and its bundled copy is stale. Do not hand out a build from it without first running cd mobile && npm run sync to copy the current code in — and even then, every future fix needs a rebuild and a reinstall on every phone, which is the problem this change exists to end.

If a native app is ever wanted again, the maintainable shape is to set server.url in capacitor.config.json to the deployed address, so the shell loads the live app instead of carrying its own copy.
